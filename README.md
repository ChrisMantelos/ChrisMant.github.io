## Features

- **Dynamic Light & Dark Mode:** A seamless toggle between a dark slate theme and a clean, accessible light theme.
- **Glassmorphic UI/UX:** Styled using modern CSS custom properties, backdrop filters, and blur effects for a sleek visual hierarchy.
- **3D Interactive Tilt Effects:** Powered by `VanillaTilt.js` for smooth, interactive card animations on hover.
- **Interactive Tech Stack Grid:** Dedicated grid layout highlighting core tools with official vector icons (FontAwesome & Devicon SVGs).
- **Education & Experience Timeline:** Custom vertical timeline showcasing ongoing academic milestones.
- **Fully Responsive & Mobile-First:** Optimized across all screen sizes, from mobile devices to high-resolution desktop displays.
- **Refined Navigation & Form:** Mobile overlay slide-out menu and an asynchronous contact form integrated with FormSubmit API and toast feedback.
- **Lightweight Architecture:** Built with pure vanilla HTML5, CSS3, and JavaScript with minimal external dependencies.
